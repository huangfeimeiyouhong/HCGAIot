# IoT 大屏 · 独立静态页交付物

把大屏重构为**单文件静态 HTML**：零构建、零后端、双击即开、可直接丢给客户或塞进任何静态托管。
现含**两块大屏**，视角不同：

| 交付物 | 视角 | 定位 |
|--------|------|------|
| `后厨管家-AIoT平台运营全景监控大屏.html` | **平台方（运营/管理侧）** ★主力 | 平台整体运行状态、核心业务数据、工单资源调度、异常告警、关键绩效指标；弱化单一租户/终端细节 |
| `后厨管家-IoT设备全景监控大屏.html` | 设备/终端运维 | 设备状态、环境监测、在线率、区域设备分布 |

> `iot-desktop` 平台后台的「总览大屏」入口（P-17）现指向**平台运营版**（`.env` 的 `VITE_COCKPIT_URL`）。

## 文件说明

| 文件 | 说明 |
|------|------|
| `template.html` / `template-platform.html` | 页面源码模板（`/*__ECHARTS__*/`、`/*__GEOJSON__*/` 为占位符） |
| `后厨管家-*.html` | **最终交付单文件**（约 1.6 MB，含 ECharts + 中国/福建 GeoJSON 内联） |
| `echarts.min.js` | ECharts 5.6.0 |
| `china.geo.js` / `fujian.geo.js` | 压缩后的 GeoJSON，`const CHINA_GEOJSON = {...}` |
| `build.sh` | 合成脚本：两份模板 → 两份单文件 |
| `verify-standalone.cjs` / `verify-standalone-platform.cjs` | 无头 Chrome 验收脚本 |

## 使用

```bash
# 改完 template*.html 后重新合成（一次生成两块大屏）
./build.sh

# 验收（1920×1080 无头 Chrome）
node verify-standalone-platform.cjs
```

## 平台运营大屏 · 页面构成（1920×1080，三栏 + 顶部状态条）

- **顶部状态条**：平台整体运行状态 —— 系统可用率 / 服务节点 / 消息队列积压 / 平均响应时延 / 今日 API 调用 / 数据同步 / 运行时长
- **左栏**：平台经营总览（入驻厂家·客户食堂·接入设备·绑定关系 4 KPI + 厂家结构环形图 + 今日新增） / 工单调度中心（状态分布堆叠条 + 厂家负载 TOP5 + 在线工程师·超时升级）
- **中栏**：核心运营指标趋势（工单量 / 设备在线率 / SLA 达标率，近 7 日） / 厂商·客户地域覆盖（中国地图，气泡=厂家、色深=客户密度）
- **右栏**：异常告警中心（三级统计 + 来源分布 + 平台级实时告警流） / 关键绩效 & 运营待办（SLA 达标率·平均响应·平均修复·故障复发率·设备在线率 + 4 项运营待办）

### 交互

| 操作 | 效果 |
|------|------|
| 点击中国地图上的**福建** | 下钻到福建省地市的厂商/客户分布，标题变「福建省 · 厂商客户分布」 |
| 地图面板「← 返回全国」 | 回到全国视图 |
| 告警列表 hover | 暂停自动滚动 |
| 右上全屏按钮 | 进入 / 退出全屏 |

数据每 60s 静默刷新（失败保持原值，不清屏）。等比缩放：非 1920×1080 的屏也完整显示。

## 设备大屏 · 页面构成（1920×1080，三栏）

- **左栏**：设备状态总览（4 KPI + 五大平台线环形图） / 环境实时监测（2×2 仪表）
- **中栏**：实时指标趋势（在线率折线 + 告警柱状） / 区域分布视图（中国地图，福建下钻）

## 接入真实平台

只需改各自 `template*.html` 里的 `fetchData()` 一处，把 mock 生成器换成 HTTP 请求
（平台版数据结构见文件内 fetchData 注释；设备版接口示例见 Git 历史版 README）。返回结构与 mock 一致，面板代码零改动。

平台版告警等级枚举：`urgent` / `important` / `normal`。
控制台调试钩子：`__iot.charts`、`__iot.mapMode`、`__iot.drill()`、`__iot.back()`。

## 踩坑记录

| 问题 | 根因 | 修法 |
|------|------|------|
| 地图面板只有 68px 高 | 面板没声明 `flex:1`，在 flex 列里没吃到剩余高度 | 加 `.pflex{flex:1;min-height:0}` |
| 环形图/负载图完全不渲染 | `.panel__bd` 不是 flex 容器，内层 `flex:1` 失效 → 高度 0 → canvas 高度 0 | 对用到内层 flex 的面板加 `.panel__bd{display:flex;flex-direction:column}`，内层 `.chart` 绝对定位 |
| 平台版下钻报 `btnBack` 为 null | 返回按钮是 `#mapExtra` 的子节点，而 `mapExtra.textContent` 每次刷新会把它整个抹掉 | 把按钮移出被覆盖 textContent 的元素，作为兄弟节点 |
| 平台版 P6 待办第 4 项被裁掉 | P6 固定高度 312px 装不下 KPI 条 + 4 项待办 | P6 加高到 356px，KPI 条 92px、待办行 40px、来源图 150px |
| 虚拟滚动索引越界 | 告警列表刷新后索引未归零 | 每次 `renderAlarms()` 重置索引 + 关过渡瞬移回顶 |

## 验收（无头 Chrome 1920×1080 跑 file://）

- 无溢出：`scrollW/H = clientW/H = 1920×1080`
- 8 个图表容器 canvas 均真实渲染（442×218 环形 / 442×86 状态条 / 442×138 负载 / 274×250×3 趋势 / 850×442 地图 / 298×150 来源）
- 状态条 7 项、KPI 4 项、副指标 3 项、告警等级 3、来源图例 5、实时告警 18 行（12+6 克隆）、KPI 绩效 5、待办 4
- 下钻：`mapMode=fujian`、标题「福建省 · 厂商客户分布」、地市列表 9 行、返回按钮可见
- console / pageerror：零
